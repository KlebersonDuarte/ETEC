# Módulo II · DS — Desenvolvimento de Sistemas

Continuação da programação em C#, migrando de aplicações de terminal para Windows Forms (interface gráfica desktop), agora com conexão a banco de dados.

## Tecnologias

- C#
- Windows Forms
- MySQL

## Como rodar

Requer um servidor MySQL em execução — pode ser instalado separadamente ou via um pacote como XAMPP ou WAMP.
