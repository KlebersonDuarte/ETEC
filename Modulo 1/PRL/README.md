Primeira disciplina de programação do curso: lógica, estrutura de programas e introdução ao C# no Visual Studio, com aplicações de terminal/console.

Alguns projetos desta pasta estão com arquivos corrompidos. Como são os exercícios iniciais do curso — focados em aprender a usar o Visual Studio e a linguagem —, o conteúdo perdido não é crítico.
